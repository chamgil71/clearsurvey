### ⑪ Anti-patterns
1. Material round 카드 사용 금지 — Fluent 2 sharp 사각(0~2px)이 Azure 표준
2. Azure 코발트를 본문 텍스트에 사용 금지 — 링크/CTA만
3. 사이드바 활성 표시를 풀-배경 칠로 만들지 말 것 — 좌측 2px 보더 라인 + 옅은 배경
4. 본문 카드를 8px 이상 라운드 금지 — Fluent 2에서 어울리지 않음
5. 가격·메트릭에 색상 강조 금지 — 검정 본문 + tabular-nums
