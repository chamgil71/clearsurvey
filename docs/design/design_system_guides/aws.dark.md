- **브랜드명**: AWS (Amazon Web Services)
- **한 줄 정체성**: 2006년 시작한 글로벌 1위 클라우드 인프라 — 200+ 서비스의 콘솔/API
- **공식 디자인 철학**: **Cloudscape Design System** — "Designed for AWS, Built for the world's largest cloud"

### ⑪ Anti-patterns
1. Amazon 본가 톤(밝은 파스텔, 둥근 카드) 사용 금지 — AWS는 짙은 네이비 + 정보 밀집

3. 리소스 ID / IP / ARN을 본문 폰트로 표시 금지 — 반드시 monospace
4. 상태 배지를 단색 칠로 만들지 말 것 — 시맨틱 배경(연하게) + 시맨틱 텍스트 + ● 도트
5. 콘솔 헤더 색에 그라데이션·라이트 톤 사용 금지 — Squid Ink #232F3E 단색
