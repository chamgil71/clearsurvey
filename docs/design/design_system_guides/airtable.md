### ① 브랜드 DNA
- **브랜드명**: Airtable
- **한 줄 정체성**: 스프레드시트의 친숙함과 관계형 DB의 힘을 합친, 누구나 쓰는 데이터 워크플로우
- **공식 디자인 철학**: "The platform to build next-generation apps — flexible, connected, no-code"
- **시그니처 요소 1개**: 6색 base color(yellow/teal/blue/red/pink/purple) + 그리드 셀의 컬러풀 select pill

### ② 톤 & 무드
- **핵심 키워드 3개**: 컬러풀, 데이터베이스적, 유연함
- **무드 설명**: 흰 캔버스 위에 정확한 그리드 라인. 셀의 select 옵션 pill이 컬러풀하게 데이터 카테고리를 표현한다.
- **비주얼 스타일**: 모던 미니멀
- **밀도(Density)**: Compact — 그리드 셀
- **모서리 성향**: Soft (4~8px)
- **평면성**: Subtle

### ⑪ Anti-patterns
1. select pill 색을 의미와 무관하게 무작위 적용 금지 — 카테고리 신호 흐림
2. 그리드 셀 라인을 두껍게 (>1px) 그리지 말 것 — 데이터 가독성 저하
3. 한 컬럼에 5개 이상 다른 select 색 동시 사용 금지
4. 본문 폰트 size 12px 미만으로 줄이지 말 것
5. 마케팅 base icon(yellow/red 반반)을 임의 그라데이션으로 대체 금지
