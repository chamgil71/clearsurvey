### ① 브랜드 DNA
- **브랜드명**: Microsoft Copilot
- **한 줄 정체성**: Microsoft 365·Windows·GitHub에 통합된 AI 어시스턴트 — Bing AI의 후신
- **공식 디자인 철학**: "Built on Fluent 2 — Empowering everyone" — 생산성 도구에 자연스럽게 녹아드는 AI
- **시그니처 요소 1개**: Copilot 그라데이션 리본 (블루 → 시안 → 퍼플 → 핑크) + Fluent 2 코발트(#0078D4). 우주 빈 원 형태의 라운드 리본 로고가 시그니처

### ② 톤 & 무드
- **핵심 키워드 3개**: 신뢰, 보조, 통합
- **무드 설명**: Fluent 2 베이스 + Copilot 액센트 그라데이션. 회색-블루 톤의 깔끔한 캔버스에 그라데이션 글래스/리본 라인이 답변·로고에 등장. Office 패밀리와 일관된 sharp-soft 모서리.
- **비주얼 스타일**: 모던 미니멀 + 글래스모피즘 (그라데이션 보더)
- **밀도(Density)**: Comfortable
- **모서리 성향**: Soft (4~8px) — Fluent 2 표준
- **평면성**: Subtle — Fluent depth 토큰 사용

### ⑪ Anti-patterns
1. Fluent 2가 아닌 Material Design 톤 사용 금지 — sharp round 4~8px이 Fluent 표준
2. Copilot 그라데이션을 본문 텍스트 가독성 해칠 정도로 진하게 사용 금지 — 로고·보더·강조 라인 한정
3. 한 화면에 그라데이션 요소 3개 이상 배치 금지 — 시선 분산
4. Segoe UI 외 다른 산세리프 단독 사용 금지 — 다른 폰트 사용 시 Fluent 정체성 손실
