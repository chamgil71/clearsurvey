### ① 브랜드 DNA
- **브랜드명**: Webflow
- **한 줄 정체성**: 코드 없이도 정밀한 웹사이트를 만드는, 디자이너와 개발자의 경계를 지운 빌더
- **공식 디자인 철학**: "No-code, no compromise — bring designers, marketers, developers together"
- **시그니처 요소 1개**: Webflow Indigo(#4353FF)→Purple 그라데이션 + 다크 도구 UI + 우측 스타일 패널의 정밀 컨트롤

### ② 톤 & 무드
- **핵심 키워드 3개**: 개발자 친화, 정밀함, 시각적
- **무드 설명**: 다크 도구 UI에 흰 캔버스 미리보기. Indigo 그라데이션이 brand mark에 강하게 박힌다. CSS 표준에 가까운 정밀 컨트롤 UI.
- **비주얼 스타일**: 모던 미니멀 (도구 톤)
- **밀도(Density)**: Compact — 도구 패널
- **모서리 성향**: Soft (4~8px)
- **평면성**: Subtle

### ⑪ Anti-patterns
1. 도구 캔버스 영역에 brand 그라데이션 배경 사용 금지 — 사용자 디자인이 주인공
2. 스타일 패널의 input height를 32px 이상으로 늘리지 말 것 — 28px 기본
3. brand 그라데이션 방향을 임의 변경 금지 — Indigo→Purple 시그니처
4. button을 pill (9999px)으로 변경 금지 — 6px 기본
5. 코드 영역 폰트를 sans-serif로 사용 금지 — 모노스페이스 필수
