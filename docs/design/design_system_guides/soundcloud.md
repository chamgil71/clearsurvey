### ① 브랜드 DNA
- **브랜드명**: SoundCloud
- **한 줄 정체성**: 크리에이터가 직접 업로드하는 오디오 소셜 플랫폼 — 데모·믹스테이프의 본진
- **공식 디자인 철학**: "Music from a different place" — 크리에이터 친화 + 파형 시각화 우선
- **시그니처 요소 1개**: 오렌지(#FF5500) 파형 플레이어 + 댓글 핀이 파형 위 시각 좌표로 박혀있는 인터랙션. 다른 음악 서비스에는 없는 사운드클라우드만의 시그니처

### ② 톤 & 무드
- **핵심 키워드 3개**: 크리에이터, 파형, 활기참
- **무드 설명**: 라이트 모드가 기본. 흰 캔버스에 오렌지가 강렬하게 박힌다. 카드 라운드 4px, 작은 아바타, 빽빽한 메타정보. UI는 정보 밀도가 높고 음악적 활기가 강조된다.
- **비주얼 스타일**: 모던 미니멀
- **밀도(Density)**: Comfortable
- **모서리 성향**: Soft (4~8px)
- **평면성**: Flat

### ⑪ Anti-patterns
1. 파형(waveform) 없이 트랙을 표시 금지 — SC의 정체성
2. 파형 색을 오렌지 외 색으로 변경 금지 — #FF5500 + faded #FFB088이 표준
3. 라이트 모드를 검정 캔버스로 변경 금지 (다크 모드 별도)
4. 카드 라운드 12px 이상 사용 금지 — 2~4px Sharp~Soft
5. 댓글 핀을 텍스트 리스트로만 표시 금지 — 파형 위 시각 좌표가 시그니처
