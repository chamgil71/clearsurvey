### ① 브랜드 DNA
- **브랜드명**: v0 (Vercel)
- **한 줄 정체성**: 자연어 → React/Next.js 컴포넌트를 즉시 생성하는 AI UI 빌더
- **공식 디자인 철학**: Vercel의 "Less, but better" — 무채색 위에 한 줄 콘텐츠
- **시그니처 요소 1개**: 순흑 #000 캔버스 + Geist 가변 폰트 + 좌측 코드 / 우측 라이브 프리뷰 2분할. 강조 색을 단 한 톤도 쓰지 않고 "흰색 한 점"만 액션 버튼에 사용

### ② 톤 & 무드
- **핵심 키워드 3개**: 미니멀, 정밀, 모노
- **무드 설명**: Vercel 디자인 언어의 연장. 그라데이션, 채도 있는 강조색을 모두 배제하고 그레이스케일 10단계만으로 위계를 만든다. AI라는 미래적 도구를 가장 조용한 형태로 제시.
- **비주얼 스타일**: 모던 미니멀
- **밀도(Density)**: Compact — 코드/UI 정보 밀도가 높음
- **모서리 성향**: Soft (6~8px)
- **평면성**: Flat

1. 그라데이션 배경 금지 — 흑백 솔리드만 (Vercel 본가 hero gradient 와 차별)
2. 채도 있는 액센트 색 UI 사용 금지 — 흰색이 유일한 강조
3. AI 응답에 형광 보색 강조 금지
4. 카드 모서리 12px 초과 금지 — 컴포넌트 시각 일관성
5. 다단 그림자 금지 — 1단계 미세 그림자만
