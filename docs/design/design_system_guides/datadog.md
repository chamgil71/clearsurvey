2. brand 보라를 본문 텍스트에 사용 금지 — 데이터 highlight에만
3. 그래프 라인을 1px 미만으로 그리지 말 것 — 시인성 저하
4. 강아지 로고를 임의 색 변경 금지
5. 다크 모드에서 풀 white(#FFF) 텍스트 사용 금지
