### ① 브랜드 DNA
- **브랜드명**: Affinity (Serif → Canva acquired)
- **한 줄 정체성**: Adobe 대안 데스크톱 크리에이티브 스위트 — Photo·Designer·Publisher 3종
- **공식 디자인 철학**: "Pro tools without subscription" — 한 번 결제로 평생 사용
- **시그니처 요소 1개**: Photo(#1B72BE)·Designer(#7E4AB2)·Publisher(#B2384A) 3색 분리 — 같은 UI 셸에 제품별 컬러만 바뀐다. Adobe Cobalt/Orange/Red와 차별되는 단일 톤 셰어드 UI

### ② 톤 & 무드
- **핵심 키워드 3개**: 3색분리, 데스크톱, 어도비대안
- **무드 설명**: 다크 그레이 캔버스(#1A1D24) + 제품별 액센트(블루/퍼플/레드). 정보 밀도 높고 sharp. Adobe와 거의 동일한 데스크톱 톤이지만 더 차분하고 통합적.
- **비주얼 스타일**: 모던 미니멀
- **밀도(Density)**: Compact
- **모서리 성향**: Sharp (2~3px)
- **평면성**: Flat
