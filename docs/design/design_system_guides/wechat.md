### ① 브랜드 DNA
- **브랜드명**: WeChat (微信, Weixin)
- **한 줄 정체성**: 중국 1위 슈퍼앱 — 메시지 + 결제 + 미니프로그램 + 모멘트 + 비디오 채널
- **공식 디자인 철학**: 化繁为简 (복잡함을 단순하게) — Allen Zhang의 절제·도구 중심
- **시그니처 요소 1개**: 두 개의 겹친 말풍선(吹) 로고 + WeChat Green(#07C160) + 보낸 말풍선의 라임 그린(#A0E75A) + 미니프로그램 4열 그리드 + 정사각형 6px 모서리 아바타. 동그란 아바타가 표준인 다른 메신저들과 정반대

### ② 톤 & 무드
- **핵심 키워드 3개**: 슈퍼앱, 실용, 단정
- **무드 설명**: 회색(#EDEDED) 채팅 배경 + 사각형 모서리 6~8px의 단정한 톤. 색은 액션과 강조에 한 점씩. 슈퍼앱답게 그리드 아이콘이 큰 비중을 차지.
- **비주얼 스타일**: 모던 미니멀
- **밀도(Density)**: Comfortable
- **모서리 성향**: Soft (4~8px) — 아바타도 라운드 사각형
- **평면성**: Flat — 그림자 거의 없음

### ⑪ Anti-patterns
1. 동그란(9999px) 아바타 사용 금지 — WeChat은 6px 라운드 사각형 아바타가 시그니처
2. 보낸 말풍선에 진한 그린 사용 금지 — 라임 #A0E75A 고수, 텍스트는 검정
3. 말풍선 모서리 14px 이상 금지 — 4px Soft가 시그니처(WhatsApp/LINE와 차별)
4. 화려한 그라데이션·일러스트 금지 — 단정한 톤, 색은 액션에만
5. 미니프로그램 진입을 텍스트 링크로만 처리 금지 — 4열 그리드 아이콘 패턴 유지
