# ClearSurvey — 기초 구현계획 수립서 (Basic Implementation Plan)

본 문서는 **ClearSurvey** 프로젝트 착수 단계에서 식별된 비즈니스 요구사항, 핵심 기술 과제, 그리고 정밀 클렌징 엔진과 시각화 대시보드를 통합 결합하기 위한 **최초 기초 구현 아키텍처 수립 설계서**입니다.

---

## 1. 프로젝트 배경 및 초기 요구사항 식별

기존의 설문 조사 및 정밀 행정 데이터 분석 업무는 다음과 같은 비효율이 존재했습니다:
1. **Raw 데이터 결측 및 오기**: 주소 누락, 형식 불일치, 연/월/일 분할 등 정합성이 맞지 않는 지저분한 원본 데이터.
2. **반복적인 수동 클렌징**: 엑셀 수식과 매크로를 이용해 분석가들이 수작업으로 매번 공식을 덮어씌우는 비효율.
3. **가시성 부족**: 클렌징 결과를 별도의 그래프 툴로 수동 연계 렌더링해야 하는 고충.

### 💡 해결 아키텍처 제안
이를 타개하기 위해, **파이썬 정밀 클렌징 파이프라인 코어**를 개발하고, 그 위에 **REST API 백엔드 서버**를 얹어 웹상에서 컬럼을 손쉽게 드롭다운으로 매핑한 뒤, **인터랙티브 웹 대시보드**까지 실시간 내보내기 형태로 자동 연결하는 풀스택 1-Click 아키텍처를 기초로 기획했습니다.

---

## 2. 기초 시스템 디자인 및 데이터 파이프라인 개요

시스템은 모듈식(Modular) 구조를 취하여 코어와 플러그인이 단단하게 분리되도록 기초 기획되었습니다.

```
[설문 원본 Excel]
       │
       ▼ (1. 뼈대 정의 - engine/config.py)
[SurveyConfig Pydantic validation]
       │
       ▼ (2. 전처리 - engine/preprocessor.py)
[행 필터링 및 Null값 채우기]
       │
       ▼ (3. 변환 알고리즘 - transforms/registry.py)
[Transforms 변환 및 검증 체인 실행]
       │
       ▼ (4. 렌더링 및 파일화 - engine/writer.py)
[openpyxl 기반 서식/요약/슬라이서 주입]
       │
       ▼
[최종 결과물.xlsx & web/data/project_data.json]
```

* **재현가능성(Reproducibility) 보장**: 설정 정보(`config.yaml` 및 `dashboard.json`)를 프로젝트 폴더 하위에 영구히 격리 보관함으로써, 차후 원본 데이터의 행수가 아무리 늘어나도 동일한 규칙으로 백퍼센트 완벽하게 동일한 결과물과 대시보드를 재조립해 낼 수 있는 재현 아키텍처를 수립했습니다.
