# ClearSurvey v2: CLI vs Web 방식 비교 가이드

ClearSurvey v2 시스템은 기존 엑셀 기반(CLI) 인터페이스의 강력함과, 새로운 웹 브라우저 기반 GUI의 직관성을 모두 제공하도록 설계되었습니다.

## 1. 핵심 차이점 요약

| 구분 | 💻 CLI 방식 (엑셀 기반) | 🌐 Web 방식 (브라우저 GUI) |
| --- | --- | --- |
| **설정 편집기** | `draft_*.xlsx` 파일의 `Config` 시트 | 웹 브라우저 관리자의 **컬럼 정제 설정** 표 |
| **작업 흐름** | 명령어 실행 → 엑셀 파일 열고 텍스트 수정 → 명령어 실행 | 파일 드래그 앤 드롭 → 화면에서 클릭/선택 → 실행 버튼 클릭 |
| **대시보드(차트)** | `dashboard.json`을 텍스트 에디터로 직접 작성 | 웹에서 차트 카드 추가/수정 후 즉각 저장 |
| **주 사용층** | 개발자, 키보드 단축키 및 엑셀 대량 셀 편집(붙여넣기)이 편한 사용자 | 데이터 담당자, 비개발자, 즉각적인 미리보기가 필요한 사용자 |

---

## 2. 웹 화면에는 왜 `draft_*.xlsx` 파일을 등록하는 메뉴가 없을까요?

웹 뷰(Web GUI) 모드의 가장 큰 개발 목적이 바로 **"불편하게 `draft_*.xlsx` 파일을 열어서 직접 타이핑하지 않기 위해서"**입니다! 상관없는 것이 아니라 아주 의도적인 설계입니다.

* **CLI 방식의 한계**: 원본을 등록하면 만들어지는 `draft_*.xlsx` 파일을 엑셀로 일일이 열어서, Config 시트에 오타 없이 `transform` 함수명 등을 키보드로 타이핑한 뒤 다시 저장해야 했습니다. 함수명을 외우고 있어야만 했습니다.
* **Web 방식의 해결책**: 사용자가 엑셀 파일을 업로드하는 순간, 백엔드가 원본을 분석하여 즉시 웹 화면에 "컬럼별 설정 인터페이스(드롭다운 리스트, 체크박스)"를 그려냅니다. 
* **결론**: **웹 화면 자체가 살아 숨쉬는 `draft_*.xlsx` 에디터 역할을 완벽히 대체**합니다. 웹 화면에서 클릭 몇 번으로 수정하고 [설정 저장]을 누르면 백엔드가 설정 파일(`config.yaml`)을 바로 기록해 주기 때문에, 엑셀 파일 형태로 설정을 덮어쓰는 기능을 웹에 넣을 필요가 없어진 것입니다. (다만 CLI 사용자나 레거시 워크플로우를 위해 서버에 파일 자체는 백업용으로 생성해두고 있습니다)

## 3. 상세 작업 워크플로우 비교

### 3.1. CLI 방식 (전통적 엑셀 편집)
1. **분석(Analyze)**
   ```bash
   uv run backend/cli.py analyze --file raw/원본데이터.xlsx --project 프로젝트명
   ```
   이 명령을 치면 `storage/projects/프로젝트명/draft_원본데이터.xlsx` 가 생성됩니다.
2. **설정(Config) 변경**
   - 만들어진 `draft_...xlsx` 파일을 엑셀 프로그램으로 직접 엽니다.
   - 2번째 시트인 **Config** 시트로 가서 `transform`, `width` 등을 사용자가 직접 키보드로 텍스트 입력합니다.
   - 파일 저장을 누르고 엑셀을 닫습니다.
3. **정제 및 실행(Run)**
   ```bash
   uv run backend/cli.py run --project 프로젝트명
   ```
   - 엔진이 `draft_...xlsx`의 Config 시트를 읽어서, 원본을 정제한 뒤 `output/프로젝트명_cleaned.xlsx` 를 최종 결과물로 만듭니다.

### 3.2. Web 방식 (최신 브라우저 편집)
1. **분석(Analyze) 및 업로드**
   - 관리자 웹페이지 접속
   - `[Step 1]` 탭에 엑셀 파일을 드래그 앤 드롭하고 프로젝트 이름을 입력.
2. **설정(Config) 변경**
   - `[Step 2]` 탭에 나타난 웹 UI 표를 확인합니다.
   - 각 열(Column)별로 마련된 `<select>` 드롭다운 박스에서 원하는 정제 규칙(`transform`)을 마우스로 선택합니다. (오타 날 걱정이 없습니다!)
   - 드래그 앤 드롭으로 차트(대시보드) 요소를 실시간 배치합니다.
   - **[설정 저장]** 버튼을 클릭합니다.
3. **정제 및 실행(Run)**
   - 하단의 **[정제 엔진 1-Click 실행]** 버튼을 클릭합니다.
   - 실시간 상태바를 보며 대기 후, 생성이 완료되면 대시보드 JSON과 정제된 엑셀 파일을 다운로드하거나 확인할 수 있습니다.

## 4. 혼합 사용 팁 (하이브리드)
만약 **기둥(Column)이 수십 수백 개인 엑셀**을 다뤄서 웹 화면에서 하나하나 클릭하는 것조차 버거울 때는, CLI 방식의 장점을 웹 개발 도중에도 차용할 수 있습니다.
- 백엔드 서버(`storage/projects/프로젝트명`)에 저장된 `draft_*.xlsx` 나 `config.yaml` 을 텍스트 에디터나 엑셀로 열어 한꺼번에 "복사/붙여넣기" 하여 대량 편집한 후 저장합니다.
- 그런 다음 웹 브라우저에서 `F5`(새로고침)를 눌러 [Step 2] 로 진입하면, 직접 수정한 대량의 내용이 **웹 화면에 그대로 반영(로드)**되는 것을 볼 수 있습니다. 그 이후부터 다시 버튼으로 실행(Run)하시면 편합니다.
